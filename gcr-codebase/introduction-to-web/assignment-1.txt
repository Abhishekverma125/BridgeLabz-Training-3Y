Real-world Example (Amazon): - Frontend: Product pages, search bar,
shopping cart. - Backend: Processes orders, payments, user
authentication. - Full-Stack: Develops both the customer interface and
server functionality.

3. How a Browser Requests and Displays a Web Page

1.  User enters a website URL.
2.  Browser sends an HTTP/HTTPS request to the web server.
3.  Server processes the request.
4.  Server sends HTML, CSS, JavaScript, and images.
5.  Browser renders the page and displays it to the user.

5. What is a Web Server?

A web server stores, processes, and delivers web pages over the
internet.

Examples: - Apache HTTP Server - Nginx - Microsoft IIS - LiteSpeed -
Tomcat

6. Roles

Frontend Developer: - Builds UI using HTML, CSS, JavaScript.

Backend Developer: - Handles server logic, APIs, and databases.

Database Administrator: - Manages databases, backups, security, and
performance.

8. Static vs Dynamic Websites

Static: - Fixed content. - Example: Portfolio website.

Dynamic: - Content changes using databases/backend. - Example: Facebook,
Amazon.

9. Web Browsers and Rendering Engines

-   Google Chrome — Blink
-   Microsoft Edge — Blink
-   Mozilla Firefox — Gecko
-   Apple Safari — WebKit
-   Opera — Blink

Rendering engines interpret HTML, CSS, and JavaScript to display web
pages.
